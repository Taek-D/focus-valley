<task type="auto">
  <name>Task 1: Install Capacitor dependencies and initialize Android project</name>
  <files>package.json, capacitor.config.ts, android/</files>
  <action>
1. Install Capacitor core runtime dependencies:
   ```
   npm install @capacitor/core @capacitor/android @capacitor/preferences @capacitor/splash-screen @capacitor/status-bar @capacitor/app
   ```

2. Install Capacitor CLI and asset generation tool as dev dependencies:
   ```
   npm install -D @capacitor/cli @capacitor/assets
   ```

3. Create `capacitor.config.ts` at the repo root (do NOT use `npx cap init` as it may overwrite — create manually):
   ```typescript
   import type { CapacitorConfig } from '@capacitor/cli';

   const config: CapacitorConfig = {
     appId: 'app.focusvalley.android',
     appName: 'Focus Valley - 집중 타이머',
     webDir: 'dist',
     server: {
       androidScheme: 'https',
     },
     plugins: {
       SplashScreen: {
         launchShowDuration: 0,
         launchAutoHide: false,
         backgroundColor: '#0a0f1a',
         androidSplashResourceName: 'splash',
         showSpinner: false,
       },
       StatusBar: {
         style: 'Dark',
         backgroundColor: '#0a0f1a',
       },
     },
   };

   export default config;
   ```

4. Run `npm run build` first to populate `dist/` (web build is fine for initial cap add).

5. Run `npx cap add android` to generate the `android/` project directory.

6. Add `android/` to `.gitignore` is NOT needed — Capacitor convention is to commit the android directory so Gradle configs and resources are version-controlled.

7. Verify `android/` directory was created with expected structure (app/build.gradle.kts, app/src/main/AndroidManifest.xml, variables.gradle or gradle.properties).

IMPORTANT: Do NOT set `server.url` in capacitor.config.ts — that is a dev-only override and must never be committed.
  </action>
  <verify>
    <automated>ls capacitor.config.ts && ls android/app/build.gradle.kts && npx tsc -b</automated>
  </verify>
  <done>capacitor.config.ts exists with appId "app.focusvalley.android". android/ directory exists with valid Gradle project. All Capacitor packages in package.json dependencies. TypeScript still compiles cleanly.</done>
</task>

<task type="auto">
  <name>Task 2: Conditional VitePWA disable and build:android script</name>
  <files>vite.config.ts, package.json</files>
  <action>
1. Modify `vite.config.ts` to conditionally exclude VitePWA when `CAPACITOR_BUILD=true`:
   - Add at the top (after existing imports): `const isCapacitorBuild = process.env.CAPACITOR_BUILD === 'true';`
   - Wrap the `VitePWA({...})` call: `!isCapacitorBuild && VitePWA({...})`
   - Add `.filter(Boolean)` to the plugins array to strip the `false` entry
   - Do NOT modify any existing VitePWA configuration — all options stay exactly as-is
   - Do NOT modify any other part of vite.config.ts (test config, build config, resolve config)

2. Install cross-env for cross-platform env var setting:
   ```
   npm install -D cross-env
   ```

3. Add two new scripts to package.json (leave all existing scripts untouched):
   ```json
   "build:android": "cross-env CAPACITOR_BUILD=true npm run build && npx cap sync android",
   "cap:open": "npx cap open android"
   ```
   cross-env is mandatory — do NOT use Windows-only `set` syntax or any platform-specific alternative. This ensures the build script works on Windows, macOS, Linux, and CI.

4. Verify the conditional works:
   - Run `npm run build` (normal web build) and confirm `dist/sw.js` exists
   - Run `npm run build:android` and confirm `dist/sw.js` does NOT exist
   - Confirm `android/app/src/main/assets/public/` has NO `sw.js` or `workbox-*.js`

CRITICAL: The web build (`npm run build`) must remain EXACTLY as before. Only the `build:android` path changes behavior.
  </action>
  <verify>
    <automated>npm run build:android && node -e "const fs=require('fs');const d='dist';const sw=fs.existsSync(d+'/sw.js');if(sw){console.error('FAIL: sw.js found in dist after Capacitor build');process.exit(1);}console.log('PASS: no sw.js in Capacitor build')" && npm run build && node -e "const fs=require('fs');if(!fs.existsSync('dist/sw.js')){console.error('FAIL: sw.js missing from web build');process.exit(1);}console.log('PASS: sw.js present in web build')"</automated>
  </verify>
  <done>Running `npm run build:android` produces dist/ with no service worker files and syncs to android/. Running `npm run build` (web) still produces sw.js and all PWA assets. Both builds succeed without errors. TypeScript compiles cleanly.</done>
