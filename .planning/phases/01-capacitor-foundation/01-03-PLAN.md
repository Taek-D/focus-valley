<task type="auto">
  <name>Task 1: Generate adaptive icon and splash screen assets</name>
  <files>android/app/src/main/res/</files>
  <action>
1. Create the asset source directory and prepare icon sources:
   ```bash
   mkdir -p assets
   ```

2. The `@capacitor/assets` tool needs source images. Since `favicon.svg` is vector art, we need a raster version at 1024x1024 for the icon. Check if a suitable large PNG exists:
   - `public/pwa-512x512.png` exists — this can be used, but 1024x1024 is preferred
   - If no 1024x1024 exists, use the 512x512 as source (the tool will upscale)

3. Copy the icon source to the expected location:
   ```bash
   cp public/pwa-512x512.png assets/icon.png
   ```
   Also create icon-only-foreground if possible (the tree on transparent background). If the existing PNG has a background, use it as-is — `@capacitor/assets` will handle the adaptive icon crop.

4. Create a splash source image. For a simple solid-color splash:
   - Create `assets/splash.png` — a 2732x2732 image with background color #0a0f1a (or use the tool's color option)
   - Alternatively, create `assets/splash-dark.png` (#0a0f1a) and `assets/splash.png` (#f5f5f7) for theme variants

5. Run the asset generation:
   ```bash
   npx @capacitor/assets generate --android
   ```
   This generates:
   - `android/app/src/main/res/mipmap-*/ic_launcher*.webp` — all density launcher icons
   - `android/app/src/main/res/drawable*/splash.png` — splash screen resources

6. Verify generated assets exist in the Android project:
   ```bash
   ls android/app/src/main/res/mipmap-hdpi/
   ls android/app/src/main/res/drawable/
   ```

7. If `@capacitor/assets generate` requires specific file naming, check its docs and adapt. The tool may expect `assets/icon.png` (1024x1024 square) and `assets/splash.png` (2732x2732 square).

IMPORTANT: Do NOT manually edit files in `android/app/src/main/res/` — always use the generation tool. Manual edits get overwritten by `cap sync`.

<task type="auto">
  <name>Task 2: Add SplashScreen.hide() and StatusBar theme sync to App.tsx</name>
  <files>src/App.tsx</files>
  <action>
1. Read `src/App.tsx` fully to understand the current structure, imports, and existing useEffect hooks.

2. Read `src/hooks/useDarkMode.ts` to understand how dark mode state is exposed (variable name for isDark).

3. Add imports to App.tsx:
   ```typescript
   import { Capacitor } from '@capacitor/core';
   import { SplashScreen } from '@capacitor/splash-screen';
   import { StatusBar, Style } from '@capacitor/status-bar';
   ```

4. Add a `useEffect` for hiding the splash screen after mount (run once):
   ```typescript
   useEffect(() => {
     if (Capacitor.isNativePlatform()) {
       SplashScreen.hide({ fadeOutDuration: 300 });
     }
   }, []);
   ```
   Place this AFTER existing initialization effects so the splash hides once the app is ready to display.

5. Add a `useEffect` for syncing StatusBar with the current dark mode state:
   ```typescript
   useEffect(() => {
     if (!Capacitor.isNativePlatform()) return;

     StatusBar.setStyle({
       style: isDark ? Style.Dark : Style.Light,
     });
     StatusBar.setBackgroundColor({
       color: isDark ? '#0a0f1a' : '#f5f5f7',
     });
     StatusBar.setOverlaysWebView({ overlay: false });
   }, [isDark]);
   ```
   Where `isDark` comes from the existing dark mode hook. Read `useDarkMode.ts` to confirm the exact variable name and adjust accordingly.

   NOTE: `StatusBar.setOverlaysWebView({ overlay: false })` is a safeguard against Android 15+ edge-to-edge behavior (Pitfall 6). It prevents the status bar from overlapping app content.

6. CRITICAL constraints:
   - All Capacitor calls guarded by `Capacitor.isNativePlatform()` — zero impact on web
   - Do NOT modify existing effects, components, or layout in App.tsx
   - Do NOT modify the MotionConfig wrapper or any animation settings
   - The status bar background colors (#0a0f1a dark, #f5f5f7 light) match the CONTEXT.md decisions exactly
   - `Style.Dark` means dark background (light icons), `Style.Light` means light background (dark icons)
  </action>
