**Step 1: Extend useAppPanels.ts**

Add a `string[]` open-stack state alongside existing booleans. The 8 panel names are: `'mixer' | 'auth' | 'history' | 'garden' | 'settings' | 'todo' | 'shortcuts' | 'breathing'`.

For each open function (openAuth, openHistory, openGarden, openSettings, openTodo, openBreathing):
- Set the boolean to true
- Push the panel name to the stack (deduplicate: filter out existing, then append)

For each close function (closeAuth, closeHistory, closeGarden, closeSettings, closeTodo, closeBreathing, closeShortcuts):
- Set the boolean to false
- Remove the panel name from the stack

For toggle functions (toggleMixer, toggleShortcuts) per Pitfall 7 from RESEARCH.md:
- Check the current boolean state. If currently open (true -> closing), pop from stack. If currently closed (false -> opening), push to stack.
- Use the callback form of setState to read current value: `setShowMixer((prev) => { if (prev) pop('mixer') else push('mixer'); return !prev; })`
- IMPORTANT: The stack update must happen inside the same callback or via a ref to stay synchronized. Use a `stackRef` pattern: maintain both `openStack` state and `openStackRef` ref. Mutations go through a helper that updates both.

Add `closeTopPanel` function:
```typescript
const closeTopPanel = useCallback((): boolean => {
  const stack = openStackRef.current;
  const top = stack[stack.length - 1];
  if (!top) return false;
  // Call the close function for the top panel
  closeFnMap[top]();
  return true;
}, []);
```
Where `closeFnMap` is a stable mapping of panel name to close callback (use useRef or useMemo to keep stable references).

Add to return object: `openStack`, `closeTopPanel`.

**Step 2: Rewrite useBackButton.ts**

Logic in the backButton listener:
1. If `panels.openStack.length > 0`: call `panels.closeTopPanel()` and return (close topmost panel regardless of session state)
2. Else if `isRunning`: call `onShowSessionGiveUpConfirm()` and return

**Step 1: Add resumeAudio to useAudioMixer.ts**

Add a new `resumeAudio` callback after the existing `initAudio` callback:
```typescript
const resumeAudio = useCallback(() => {
  const ctx = contextRef.current;
  if (!ctx) return;
  if (ctx.state === 'suspended') {
    void ctx.resume();
  }
}, []);
```

Add `resumeAudio` to the return object alongside existing `initAudio`, `volumes`, etc.

This is the ONLY change to useAudioMixer.ts. The appStateChange listener that calls resumeAudio will be wired in Plan 03 (App.tsx).
