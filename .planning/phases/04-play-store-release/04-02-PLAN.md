    Detailed step-by-step instructions are in how-to-verify below.
  </action>
  <how-to-verify>
    **Pre-requisites:**
    - Signed AAB from Plan 01: `android/app/build/outputs/bundle/release/app-release.aab`
    - Privacy policy live at: `https://focus-valley.vercel.app/privacy.html` (deploy web changes first if not already deployed: `npx vercel --prod`)
    - Store listing text in `store-listing/` directory

    **Play Console Steps:**

    **1. Create App**
    - Go to [Play Console](https://play.google.com/console)
    - Create app > App name: "Focus Valley - 포모도로 타이머"
    - Default language: English (en-US)
    - App type: App, Free, Category: Productivity

    **2. Store Listing (Main store listing)**
    - Short description: Copy from `store-listing/short-description-en.txt`
    - Full description: Copy from `store-listing/full-description-en.txt`
    - Add Korean (ko) translation:
      - Short description: Copy from `store-listing/short-description-ko.txt`
      - Full description: Copy from `store-listing/full-description-ko.txt`

    **3. Screenshots and Graphics**
    - Upload minimum 4 phone screenshots (real device captures, no mockup frames):
      1. Timer + plant growth (main screen, light mode)
      2. Garden collection view
      3. Dark mode view
      4. One more at your choice (sound mixer, statistics, or todo list)
    - Feature graphic (1024x500): Create pixel art themed graphic with plants from the app
    - App icon: Will be pulled from the AAB automatically

    **4. Content Rating**
    - Start questionnaire > Select "Utility, Productivity, Communication, or other"
    - Answer all questions "No" (no violence, sexual content, gambling, etc.)
    - Expected result: Everyone (E) / PEGI 3

    **5. Data Safety Form**
    Fill out the Data Safety section:
    - Does your app collect or share any user data? **Yes**
    - Data types collected:
      - Personal info > Email address: Collected, not shared. Purpose: App functionality (account). Required.
      - Personal info > Name: Collected, not shared. Purpose: App functionality (profile display). Optional.
      - App activity > App interactions (garden, sessions, todos): Collected, not shared. Purpose: App functionality. Required for signed-in users.
      - App info and performance > Crash logs: Collected, not shared. Purpose: Analytics (Sentry). Required.
      - App info and performance > Other app performance data: Collected, not shared. Purpose: Analytics (GA4). Required.
    - Encryption: All data encrypted in transit (HTTPS)
    - Deletion: Users can request data deletion (in-app Delete Account button + email)
    - Privacy policy URL: `https://focus-valley.vercel.app/privacy.html`

    **6. Upload AAB**
    - Go to Production > Create new release
    - Upload `android/app/build/outputs/bundle/release/app-release.aab`
    - Enroll in Google Play App Signing when prompted (recommended)
    - Release name: "1.1.0"
    - Release notes (EN): "Initial release of Focus Valley for Android. Grow your pixel art garden while staying focused!"
    - Release notes (KO): "Focus Valley 안드로이드 첫 출시. 집중하며 픽셀 아트 정원을 가꿔보세요!"

    **7. Review and Submit**
    - Check all sections show green checkmarks in the Dashboard
    - Review and roll out to Production (or Internal testing first if preferred)
    - Expected review time: 1-7 days for new apps

    **Verification after submission:**
    - Play Console shows "In review" or "Published" status
    - Privacy policy URL is accessible publicly
    - Data Safety form shows as complete
